Все промо-кадры — игровой процесс. Кадр меню использовать нельзя: модерация
считает его негеймплейным (п. 5.1.1.2, «геймплей менее 70%»).

Ролики пересобираются (нужен запущенный `npm run serve`):

- `npm run promo-video` — вертикальный 1080×1920, снимается мобильным макетом;
- `npm run promo-video-wide` — горизонтальный 1920×1080, десктопным макетом.

Требования площадки: MP4, не меньше 720p — берём Full HD, ролик короче
30 секунд, в кадре только геймплей, без элементов браузера, ОС и брендинга
площадки. Содержимое каждый раз новое — игры выпадают случайно, так что можно
перезапустить и взять дубль получше.

## Чек-лист подачи (шаги в консоли, не в коде)

- [ ] Включить тумблер **«Игра использует облачные сохранения»** (используем `player.setData`).
- [ ] Настройки **5 лидербордов**: сортировка «больше = лучше», тип «целое число».
      Имена уже совпадают: `leadtotal`, `leadicons`, `leadshots`, `leadtimetotal`, `leadhardcore`.
- [ ] Возрастной рейтинг **16+** (выставлен модерацией, не менять).
- [ ] Загрузить архив, обложку, иконку, 8 промо-скриншотов и оба ролика (см. таблицу).
      Без видео карточку на модерацию не отправить.
- [ ] Скопировать тексты полей (выше) — в том числе заново «Об игре», там сменилось название.
- [ ] ⚠️ Главный остаточный риск — **права** на иконки/скриншоты (п. 3.5).
      Комментарий модератору это смягчает, но не снимает.
